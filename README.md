# FCTUC-ACA 2024/2025 

Projects made for 2024/2025 edition of Advanced Machine Learning course

## Summary

**Theme 1**: Dermatology with Machine Learning

**Objective 1**: This project explores three different deep learning architectures (MLP, CNN, and [EfficientNet](https://arxiv.org/abs/1905.11946)) for image classification of skin diseases using the [DermaMNIST](https://arxiv.org/pdf/2110.14795) dataset. 

**Theme 2**: Generative Models for Blood Cell Image Synthesis on BloodMNIST

**Objective 2**: This project experiments with various generative frameworks (VAEs, GANs, and Diffusion Models) for blood cell image synthesis using the [BloodMNIST](https://arxiv.org/pdf/2110.14795) dataset.
